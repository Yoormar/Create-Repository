DASHBOARD DYNAMIC V8 - INSTALACION SEGURA

OBJETIVO
- Agregar DYNAMIC al dashboard actual.
- Mantener intactos Codigo.gs, Scripts.html, Dashboard.html y los ajustes existentes.
- Evitar que la pantalla quede bloqueada por el cargador mientras termina la carga completa.
- Agregar DYNAMIC en filtros, KPI, barras, tablas diarias y ranking.

ARCHIVOS NUEVOS
1. DashboardDynamicV8.gs
2. DashboardDynamicV8UI.html

PASOS
1. En Apps Script pulsa + y crea un archivo de secuencia de comandos llamado:
   DashboardDynamicV8
   Pega el contenido de DashboardDynamicV8.gs.

2. Pulsa + y crea un archivo HTML llamado:
   DashboardDynamicV8UI
   Pega el contenido de DashboardDynamicV8UI.html.

3. Abre Index.html.
   NO BORRES NADA.
   Al final de los includes actuales, preferentemente DESPUES de AjusteCargaDashboardUI y AjusteCierreDashboardUI, agrega solo esta linea:

   <?!= incluir('DashboardDynamicV8UI'); ?>

4. Guarda el proyecto.

5. Implementar > Administrar implementaciones > Editar > Version nueva > Implementar.

6. Abre /exec y actualiza con Ctrl+F5.

QUE DEBE APARECER
- Filtro: Dynamic.
- KPI: Atendidos Dynamic.
- Atendidos por plataforma: Dynamic.
- Vista diaria: columna Dynamic.
- Atencion diaria global: Ing. Dynamic y ATC Dynamic.
- Atencion diaria ordenable: ATC Dynamic.
- Ranking: ATC Dynamic hoy.
- Bandeja: filtro DYNAMIC.

REVERSA
Para volver exactamente al estado anterior:
- Quita la unica linea <?!= incluir('DashboardDynamicV8UI'); ?> de Index.html.
- Puedes dejar o borrar los dos archivos nuevos. Ningun archivo existente fue reemplazado.

NOTA DE RENDIMIENTO
Este complemento usa una llamada ligera independiente con cache de 90 segundos para los datos de plataforma y elimina el bloqueo visual que ocultaba todo el dashboard mientras esperaba la carga pesada existente.

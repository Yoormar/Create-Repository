Sube tu archivo de productos en CSV o JSON para actualizar la tienda

📁

Arrastra tu archivo aquí o haz clic para seleccionar

Formatos: .csv, .json

Formato del archivo CSV

La primera fila debe contener los encabezados. Columnas requeridas:

nombre, descripcion, precio, categoria, stock, imagen
  • nombre — Nombre del producto (obligatorio)
  • descripcion — Descripción breve
  • precio — Precio en soles (ej: 12.50)
  • categoria — Ej: Medicamentos, Vitaminas, Cuidado personal
  • stock — Cantidad disponible (número)
  • imagen — URL de imagen (opcional)

Ejemplo JSON

[
  {
    "nombre": "Paracetamol 500mg",
    "descripcion": "Caja x 20 tabletas",
    "precio": 5.50,
    "categoria": "Medicamentos",
    "stock": 100,
    "imagen": ""
  }
]
